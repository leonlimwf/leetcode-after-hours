# 387. First Unique Character in a String

Assigned: **2026-11-29** · **Easy**

## Problem Statement

Given a string s, return the index of its first character that appears only once. If every character repeats, return -1. Try this independently before reading a solution.


## Input and Output

Input  A string s containing lowercase English letters.

Output  The index of the first non-repeating character, or -1 if none exists.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | s = "leetcode" | 0 | The first non-repeating character is 'l' at index 0. |
| 2 | s = "loveleetcode" | 2 | The first character that occurs once is 'v' at index 2. |
| 3 | s = "aabb" | -1 | Every character appears more than once. |

## Constraints

1 <= s.length <= 10^5. s contains only lowercase English letters.
