## Problem Statement

Given nums, where nums[i] is the farthest number of positions you may move forward from index i, find the fewest jumps needed to reach the last index from index 0. The last index is guaranteed to be reachable. Try it independently before reading a solution.


## Input and Output

Input  An integer array nums; nums[i] is the maximum forward distance from index i.

Output  Return the minimum number of jumps needed to reach the last index.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [2,3,1,1,4] | 2 | The minimum jump count is 2. |
| 2 | nums = [2,3,0,1,4] | 2 | The minimum jump count is 2. |

## Constraints

1 <= nums.length <= 10^4 • 0 <= nums[i] <= 1000 • The last index is reachable.
