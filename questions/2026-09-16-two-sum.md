# 1. Two Sum

Assigned: **2026-09-16** · **Easy**

Topics: Array / Hash Table

[Open on LeetCode](https://leetcode.com/problems/two-sum/)

Status: **Accepted**

## Problem Statement

Given an integer array nums and an integer target, return the indices of two different elements whose values add up to target. Every input has exactly one valid pair, and the two elements may be returned in either order. The same array element cannot be used twice.


## Input and Output

Input  An integer array nums and an integer target.

Output  A two-element array containing the zero-based indices of the matching values.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [2, 7, 11, 15] target = 9 | [0, 1] | 2 + 7 = 9 |
| 2 | nums = [3, 2, 4] target = 6 | [1, 2] | 2 + 4 = 6 |
| 3 | nums = [3, 3] target = 6 | [0, 1] | The two equal values are at different indices |

## Constraints

2 <= nums.length <= 10^4 • -10^9 <= nums[i] <= 10^9 • -10^9 <= target <= 10^9 • Exactly one valid answer exists.

Interview follow-up Can you design an approach that runs in less than O(n^2) time?
