## Problem Statement

Given an integer array nums, move every zero to the end while keeping the non-zero values in their original order. Do this in place without making a copy of the array.


## Input and Output

Input  An integer array nums.

Output  Modify nums in place so all zeros are at the end and the non-zero values keep their order.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [0,1,0,3,12] | [1,3,12,0,0] | The non-zero values remain in order, and the zeros move to the end. |
| 2 | nums = [0] | [0] | The only value is already zero. |

## Constraints

1 <= nums.length <= 10^4 • -2^31 <= nums[i] <= 2^31 - 1
