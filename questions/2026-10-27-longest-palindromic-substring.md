# 5. Longest Palindromic Substring

Assigned: **2026-10-27** · **Medium**

Topics: String / Two Pointers / Dynamic Programming

[Open on LeetCode](https://leetcode.com/problems/longest-palindromic-substring/)

Status: **Assigned**

## Problem Statement

Given a string s, return one longest contiguous substring that reads the same forward and backward. If more than one answer has the maximum length, return any of them.


## Input and Output

Input  A string s containing digits and English letters.

Output  Return a longest palindromic contiguous substring of s.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | s = "babad" | "bab" | "bab" is a palindrome; "aba" is also a valid longest answer. |
| 2 | s = "cbbd" | "bb" | The two middle letters form the longest palindromic substring. |

## Constraints

1 <= s.length <= 1000 • s consists only of digits and English letters.
