# 53. Maximum Subarray

## Problem Statement

Given an integer array nums, find the contiguous subarray with the largest sum and return that sum. The subarray must contain at least one element.


## Input and Output

Input  An integer array nums.

Output  The largest sum of any non-empty contiguous subarray.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4] | 6 | The subarray [4, -1, 2, 1] has the largest sum. |
| 2 | nums = [1] | 1 | The only non-empty subarray is [1]. |
| 3 | nums = [5, 4, -1, 7, 8] | 23 | The entire array has the largest sum. |

## Constraints

1 <= nums.length <= 10^5 • -10^4 <= nums[i] <= 10^4
