## Problem Statement

Given two strings s and t, return true if s appears in t as a subsequence, or false otherwise. A subsequence keeps the original character order but may skip characters.


## Input and Output

Input  Two strings, s and t.

Output  Return true if s is a subsequence of t; otherwise return false.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | s = "abc", t = "ahbgdc" | true | The characters a, b, and c appear in t in the same order, with other characters between them. |
| 2 | s = "axc", t = "ahbgdc" | false | The x in s does not appear after a in t, so s cannot be formed in order. |

## Constraints

0 <= len(s) <= 100 • 0 <= len(t) <= 10^4 • s and t contain lowercase English letters.
