## Problem Statement

Given distinct positive integers candidates and a target, list every unique combination whose values sum to the target. You may reuse a candidate any number of times. Try the problem independently before reading a solution.


## Input and Output

Input  An integer array candidates and an integer target.

Output  Return all unique combinations that sum to target, in any order.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | candidates = [2, 3, 6, 7], target = 7 | [[2, 2, 3], [7]] | Both listed combinations total 7. |
| 2 | candidates = [2, 3, 5], target = 8 | [[2, 2, 2, 2], [2, 3, 3], [3, 5]] | Each listed combination totals 8. |

## Constraints

1 <= candidates.length <= 30 • 2 <= candidates[i] <= 40 • Values are distinct • 1 <= target <= 40 • Fewer than 150 valid combinations
