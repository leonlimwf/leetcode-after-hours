## Problem Statement

Given an integer x, return true if it reads the same from left to right and right to left; otherwise, return false. Try this independently before reading a solution.


## Input and Output

Input  An integer x.

Output  True if x is a palindrome; otherwise, false.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | x = 121 | true | 121 reads the same forward and backward. |
| 2 | x = -121 | false | Reversing it puts the minus sign after the digits. |
| 3 | x = 10 | false | Reversed, 10 becomes 01, which is different. |

## Constraints

-2^31 <= x <= 2^31 - 1.
