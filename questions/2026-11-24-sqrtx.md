## Problem Statement

Given a non-negative integer x, return its square root rounded down to the nearest integer. Do not use a built-in exponent or square-root operation. Try this independently before reading a solution.


## Input and Output

Input  A non-negative integer x.

Output  The integer part of the square root of x.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | x = 4 | 2 | The square root of 4 is exactly 2. |
| 2 | x = 8 | 2 | The square root is about 2.828, so rounding down gives 2. |

## Constraints

0 <= x <= 2^31 - 1.
