# 55. Jump Game

## Problem Statement

You start at index 0 of an integer array nums. Each value tells you the farthest number of positions you may move forward from that index. Return true if you can reach the last index; otherwise return false. Try this independently before reading a solution.


## Input and Output

Input  An integer array nums; each value is the maximum forward jump from that position.

Output  Return true if the last index is reachable from index 0; otherwise return false.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [2,3,1,1,4] | true | A sequence of jumps can reach the final index. |
| 2 | nums = [3,2,1,0,4] | false | The zero at index 3 blocks progress before the final index. |

## Constraints

1 <= nums.length <= 10^4 • 0 <= nums[i] <= 10^5
