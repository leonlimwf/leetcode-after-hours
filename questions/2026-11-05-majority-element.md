## Problem Statement

Given an array nums of size n, return the majority element: the value appearing more than floor(n / 2) times. You may assume that a majority element always exists. Try it independently before reading a solution.


## Input and Output

Input  An integer array nums of size n.

Output  Return the element that appears more than floor(n / 2) times.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [3,2,3] | 3 | 3 appears more than half of the three array elements. |
| 2 | nums = [2,2,1,1,1,2,2] | 2 | 2 appears four times, more than half of the seven elements. |

## Constraints

n == nums.length • 1 <= n <= 5 * 10^4 • -10^9 <= nums[i] <= 10^9 • The input is guaranteed to contain a majority element.
