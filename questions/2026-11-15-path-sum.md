# 112. Path Sum

Assigned: **2026-11-15** · **Easy**

## Problem Statement

Given the root of a binary tree and an integer targetSum, determine whether a root-to-leaf path has values that add up to targetSum. A leaf has no children. Try this independently before reading a solution.


## Input and Output

Input  The root of a binary tree and an integer targetSum.

Output  Return true if a root-to-leaf path sums to targetSum; otherwise return false.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22 | true | A root-to-leaf path totals 22. |
| 2 | root = [1,2,3], targetSum = 5 | false | No root-to-leaf path totals 5. |
| 3 | root = [], targetSum = 0 | false | An empty tree has no root-to-leaf path. |

## Constraints

0 <= number of nodes <= 5 * 10^3 • -10^3 <= Node.val <= 10^3 • -10^3 <= targetSum <= 10^3
