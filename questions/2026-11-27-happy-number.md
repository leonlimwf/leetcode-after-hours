## Problem Statement

Starting with a positive integer n, repeatedly replace it with the sum of the squares of its digits. Return true if the sequence reaches 1; otherwise return false if it enters a cycle that does not include 1. Try this independently before reading a solution.


## Input and Output

Input  A positive integer n.

Output  True if the process reaches 1; otherwise, false.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | n = 19 | true | Repeated digit-square sums reach 1. |
| 2 | n = 2 | false | The sequence loops without reaching 1. |

## Constraints

1 <= n <= 2^31 - 1.
