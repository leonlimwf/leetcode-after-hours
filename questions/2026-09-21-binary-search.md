## Problem Statement

Given a sorted array of distinct integers nums and an integer target, return the index of target if it exists. If target is not present, return -1.


## Input and Output

Input  A sorted integer array nums and an integer target.

Output  The zero-based index of target, or -1 if target is absent.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [-1, 0, 3, 5, 9, 12] target = 9 | 4 | 9 is at index 4. |
| 2 | nums = [-1, 0, 3, 5, 9, 12] target = 2 | -1 | 2 is not in the array. |
| 3 | nums = [5] target = 5 | 0 | The only value matches the target. |

## Constraints

1 <= nums.length <= 10^4 • -10^4 < nums[i], target < 10^4 • All integers in nums are distinct. • nums is sorted in ascending order.
