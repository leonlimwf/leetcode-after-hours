# 19. Remove Nth Node From End of List

Assigned: **2026-11-17** · **Medium**

Topics: Linked List / Two Pointers

## Problem Statement

Given the head of a linked list, remove the node that is nth from the end and return the updated head. Try this independently before reading a solution.


## Input and Output

Input  The linked list head and the integer n.

Output  The list head after removing the nth node from the end.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | head = [1,2,3,4,5], n = 2 | [1,2,3,5] | Remove the second node from the end, which has value 4. |
| 2 | head = [1], n = 1 | [] | The only node is removed. |
| 3 | head = [1,2], n = 1 | [1] | The final node is removed. |

## Constraints

1 <= sz <= 30 • 0 <= Node.val <= 100 • 1 <= n <= sz
