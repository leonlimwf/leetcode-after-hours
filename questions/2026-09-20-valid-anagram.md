## Problem Statement

Given two strings s and t, return true if t is an anagram of s; otherwise return false. An anagram uses every character from the original string exactly once, rearranged.


## Input and Output

Input  Two strings s and t containing lowercase English letters.

Output  Return true if t is an anagram of s; otherwise return false.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | s = "anagram" t = "nagaram" | true | The same letters appear with the same counts. |
| 2 | s = "rat" t = "car" | false | The letters and their counts do not match. |
| 3 | s = "a" t = "aa" | false | The second string contains one extra character. |

## Constraints

1 <= s.length, t.length <= 5 * 10^4 • s and t consist of lowercase English letters.
