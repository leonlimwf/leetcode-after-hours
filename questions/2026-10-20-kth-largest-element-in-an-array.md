# 215. Kth Largest Element in an Array

## Problem Statement

Given an unsorted integer array nums and an integer k, return the value that would be in position k if the numbers were arranged from largest to smallest. Duplicate values count as separate elements. Try this independently before reading a solution.


## Input and Output

Input  An integer array nums and an integer k.

Output  Return the kth largest value in nums; the result is not required to be distinct.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [3,2,1,5,6,4], k = 2 | 5 | In descending order, 5 is the second element. |
| 2 | nums = [3,2,3,1,2,4,5,5,6], k = 4 | 4 | The fourth value in descending order is 4; duplicates each count. |

## Constraints

1 <= k <= nums.length <= 10^5 • -10^4 <= nums[i] <= 10^4
