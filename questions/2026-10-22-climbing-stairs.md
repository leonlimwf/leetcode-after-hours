## Problem Statement

You are climbing a staircase with n steps. Each move can cover either one step or two. Return the number of distinct sequences of moves that reach exactly the top. Try this independently before reading a solution.


## Input and Output

Input  An integer n, the number of steps.

Output  Return the number of distinct ways to climb exactly n steps.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | n = 2 | 2 | The two move sequences are 1 + 1 and 2. |
| 2 | n = 3 | 3 | The three move sequences are 1 + 1 + 1, 1 + 2, and 2 + 1. |

## Constraints

1 <= n <= 45
