## Problem Statement

Given an array nums where each value is the money in one house, choose houses so that no two neighboring houses are selected and the total is as large as possible. Return that maximum total. Try this independently before reading a solution.


## Input and Output

Input  An integer array nums; each value is the money in one house.

Output  Return the maximum amount that can be taken without choosing adjacent houses.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [1,2,3,1] | 4 | The first and third houses total 4, with no neighboring houses chosen. |
| 2 | nums = [2,7,9,3,1] | 12 | The first, third, and fifth houses total 12, with no neighboring houses chosen. |

## Constraints

1 <= nums.length <= 100 • 0 <= nums[i] <= 400
