# 205. Isomorphic Strings

## Problem Statement

Given strings s and t, decide whether each character in s can be consistently replaced to form t, with no two different characters in s mapping to the same character. Return true if they are isomorphic and false otherwise. Try this independently before reading a solution.


## Input and Output

Input  Two strings s and t of equal length.

Output  Return true if s and t are isomorphic; otherwise return false.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | s = "egg", t = "add" | true | Each character in s maps consistently to one character in t. |
| 2 | s = "f11", t = "b23" | false | The character 1 would need to map to both 2 and 3. |

## Constraints

1 <= s.length == t.length <= 5 * 10^4 • s and t consist of valid ASCII characters.
