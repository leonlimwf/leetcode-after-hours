## Problem Statement

Given an integer array nums and an integer k, return the k most frequent elements. You may return the answer in any order.


## Input and Output

Input  An integer array nums and an integer k.

Output  A list containing the k values that occur most frequently in nums, in any order.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [1, 1, 1, 2, 2, 3] k = 2 | [1, 2] | 1 and 2 are the two most frequent values. |
| 2 | nums = [1] k = 1 | [1] | The only value is also the most frequent. |
| 3 | nums = [4, 4, 4, 5, 5, 6, 6, 6] k = 2 | [4, 6] | 4 and 6 each occur three times, more than 5. |

## Constraints

1 <= nums.length <= 10^5 • 1 <= k <= number of distinct elements in nums • -10^4 <= nums[i] <= 10^4
