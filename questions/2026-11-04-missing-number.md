## Problem Statement

Given an array nums with n distinct values from 0 through n, find and return the one value missing from that range. Try it independently before reading a solution.


## Input and Output

Input  An integer array nums containing distinct values in [0, n].

Output  Return the single number from [0, n] that is absent from nums.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [3,0,1] | 2 | The range is [0,3], and 2 is the only value missing. |
| 2 | nums = [0,1] | 2 | The range is [0,2], and 2 is missing. |
| 3 | nums = [9,6,4,2,3,5,7,0,1] | 8 | The range is [0,9], and 8 is the only value absent. |

## Constraints

n == nums.length • 1 <= n <= 10^4 • 0 <= nums[i] <= n • All values are unique.
