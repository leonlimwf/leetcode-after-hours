## Problem Statement

Given an m by n grid, start at its upper-left cell and reach its lower-right cell. From each cell, you may move only right or down. Return the number of distinct paths. Try independently before reading a solution.


## Input and Output

Input  Two integers m and n, the grid row count and column count.

Output  Return the number of distinct paths from the upper-left to the lower-right cell.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | m = 3, n = 7 | 28 | The grid has 28 distinct valid paths. |
| 2 | m = 3, n = 2 | 3 | Three different move sequences reach the destination. |

## Constraints

1 <= m, n <= 100 • The answer is guaranteed to be <= 2 * 10^9.
