## Problem Statement

Roman numerals use seven symbols: I, V, X, L, C, D and M. They are generally written from larger to smaller values; the pairs IV, IX, XL, XC, CD, and CM use subtraction. Given a valid Roman numeral string s, return its integer value. Try this independently before reading a solution.


## Input and Output

Input  A valid Roman numeral string s.

Output  The integer value represented by s.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | s = "III" | 3 | III is 1 + 1 + 1. |
| 2 | s = "LVIII" | 58 | L is 50, V is 5, and III is 3. |
| 3 | s = "MCMXCIV" | 1994 | M, CM, XC, and IV represent 1000, 900, 90, and 4. |

## Constraints

1 <= s.length <= 15 • s contains only I, V, X, L, C, D, M • s is valid and represents a value from 1 to 3999.
