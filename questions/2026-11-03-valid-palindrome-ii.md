## Problem Statement

Given a string s, decide whether it can become a palindrome after deleting at most one character. Try it independently before reading a solution.


## Input and Output

Input  A string s.

Output  Return true if deleting zero or one character can make s a palindrome; otherwise return false.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | s = "aba" | true | The string already reads the same from both ends. |
| 2 | s = "abca" | true | Deleting the mismatching c leaves a palindrome. |
| 3 | s = "abc" | false | Neither single deletion can make the remaining string a palindrome. |

## Constraints

1 <= s.length <= 10^5 • s consists of lowercase English letters.
