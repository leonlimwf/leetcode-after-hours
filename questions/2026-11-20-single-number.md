# 136. Single Number

Assigned: **2026-11-20** · **Easy**

Topics: Array / Bit Manipulation

[Open on LeetCode](https://leetcode.com/problems/single-number/)

Status: **Assigned**

## Problem Statement

Given a non-empty integer array nums where every value appears twice except for one value that appears once, return that single value. Your solution should run in linear time and use constant extra space. Try this independently before reading a solution.


## Input and Output

Input  A non-empty integer array nums.

Output  The integer value that appears only once.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [2,2,1] | 1 | 1 is the only value that appears once. |
| 2 | nums = [4,1,2,1,2] | 4 | 4 appears once; each other value appears twice. |

## Constraints

1 <= nums.length <= 3*10^4 • -3*10^4 <= nums[i] <= 3*10^4 • Every value appears twice except one.
