## Problem Statement

Given an integer array nums and an integer k, count the non-empty contiguous subarrays whose elements sum to k. Try the problem before reading a solution or hint.


## Input and Output

Input  An integer array nums and an integer k.

Output  The number of non-empty contiguous subarrays whose sum is exactly k.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [1, 1, 1], k = 2 | 2 | The first two and last two values each total 2. |
| 2 | nums = [1, 2, 3], k = 3 | 2 | [1, 2] and [3] are the two qualifying subarrays. |

## Constraints

1 <= nums.length <= 2 * 10^4 • -1000 <= nums[i] <= 1000 • -10^7 <= k <= 10^7
