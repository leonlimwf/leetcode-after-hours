# 344. Reverse String

## Problem Statement

Given an array of characters s, reverse the character order in place using O(1) extra memory. Try this independently before reading a solution.


## Input and Output

Input  An array of characters s.

Output  Reverse the characters in s in place.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | s = ["h","e","l","l","o"] | ["o","l","l","e","h"] | The characters appear in reverse order. |
| 2 | s = ["H","a","n","n","a","h"] | ["h","a","n","n","a","H"] | This is the input sequence in reverse order. |

## Constraints

1 <= s.length <= 10^5 • s[i] is a printable ASCII character.
