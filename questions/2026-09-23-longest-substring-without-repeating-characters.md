# 3. Longest Substring Without Repeating Characters

Assigned: **2026-09-23** · **Medium**

## Problem Statement

Given a string s, find the length of the longest substring that contains no repeated characters.


## Input and Output

Input  A string s containing English letters, digits, symbols, and spaces.

Output  Return the length of the longest substring without repeating characters.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | s = "abcabcbb" | 3 | The longest substring without repeating characters is "abc". |
| 2 | s = "bbbbb" | 1 | Only one distinct character can be included. |
| 3 | s = "pwwkew" | 3 | The longest valid substring is "wke". |

## Constraints

0 <= s.length <= 5 * 10^4 • s consists of English letters, digits, symbols, and spaces.
