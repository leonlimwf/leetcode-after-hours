## Problem Statement

Given an integer array nums, determine whether any value appears at least twice. Return true if a duplicate exists; otherwise return false.


## Input and Output

Input  An integer array nums.

Output  Return true if any value occurs more than once; otherwise return false.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | nums = [1, 2, 3, 1] | true | The value 1 appears twice. |
| 2 | nums = [1, 2, 3, 4] | false | All values are distinct. |
| 3 | nums = [1, 1, 1, 3, 3, 4, 3, 2, 4, 2] | true | At least one value appears more than once. |

## Constraints

1 <= nums.length <= 10^5 • -10^9 <= nums[i] <= 10^9
