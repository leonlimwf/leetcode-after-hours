# 121. Best Time to Buy and Sell Stock

Assigned: **2026-09-18** · **Easy**

Topics: Array / Dynamic Programming

[Open on LeetCode](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/)

Status: **Accepted**

## Problem Statement

Given an array prices where each value is the stock price on that day, choose one day to buy and a later day to sell. Return the greatest profit from that single transaction, or 0 if no trade can make a profit.


## Input and Output

Input  An integer array prices, where prices[i] is the stock price on day i.

Output  The maximum profit from one buy followed by a later sell, or 0 when no profitable trade exists.


## Examples

| # | Input | Output | Why it works |
| --- | --- | --- | --- |
| 1 | prices = [7, 1, 5, 3, 6, 4] | 5 | Buying at 1 and selling later at 6 earns a profit of 5. |
| 2 | prices = [7, 6, 4, 3, 1] | 0 | No later price is higher than an earlier one, so no trade is profitable. |

## Constraints

1 <= prices.length <= 10^5 • 0 <= prices[i] <= 10^4
